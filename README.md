# Adaptive E-Learning System

## About

An AI-powered e-learning platform that provides personalized learning using **learner performance and behaviour**.

Students can upload study materials and use AI to understand, practice, and revise the content.

## Features

* Upload PDF/Text study materials
* AI-generated summaries
* AI-generated flashcards
* Adaptive MCQ quizzes
* AI Tutor for answering questions
* Learner performance analysis
* Personalized practice based on weak topics

## Technologies Used

* **Python**
* **Flask**
* **Google Gemini API**
* **Gemini 2.5 Flash**
* **PyPDF / PyMuPDF**
* **HTML, CSS, JavaScript**

## How to Run

1. Clone the repository.
2. Install the required Python packages:

```bash
pip install -r requirements.txt
```

3. Add your Gemini API key to `.env`:

```env
GEMINI_API_KEY=your_api_key
```

4. Run the Flask application:

```bash
python app.py
```

5. Open the web application in your browser.
